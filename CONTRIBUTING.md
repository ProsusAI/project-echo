# Contributing to Project Echo

Thank you for your interest in contributing to Project Echo.

## Contributor License Agreement (CLA)

By contributing, you agree to assign copyright of your contribution to MIH AI B.V.
Your contributions are licensed under the Apache License, Version 2.0, consistent
with the license of this project.

## How to contribute

1. Fork the repository and create a feature branch.
2. Make your changes with clear commit messages.
3. Ensure your code includes the standard Apache-2.0 source header (see `.oss-fix-header.txt`).
4. Open a pull request describing the change and its motivation.

## Reporting issues

Please use the issue tracker to report bugs or request features. Do not include
secrets, credentials, or confidential information in issues or pull requests.
